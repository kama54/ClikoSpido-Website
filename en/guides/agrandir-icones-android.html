Make Android icons larger

Android may offer separate settings for text size, screen zoom and home screen icon layout. The exact choices depend on the phone.

Increase text size

In Settings, search for Font size. Adjust gradually and check the labels.

Try display scaling

Search for Display size, Screen zoom or an equivalent accessibility setting.

Check the home screen grid

Some launchers let you use fewer icons per row, making each one larger.

Check the result

Make sure contacts, buttons and navigation remain fully visible.

A simplified launcher with large controls may help when built-in display settings are not enough.
