Installer ClikoSpido depuis Google Play

ClikoSpido Launcher simplifie l’écran d’accueil d’un smartphone Android compatible. Son installation ne supprime pas vos contacts, photos ni messages.

  1. Ouvrez la fiche ClikoSpido sur Google Play.
  2. Touchez Installer, puis Ouvrir.
  3. À la première ouverture, vérifiez la langue proposée. Vous pouvez en choisir une autre avant de créer le code PIN.
Bon à savoir

ClikoSpido peut fonctionner comme un nouvel accueil sans devenir votre application Téléphone par défaut. Ce sont deux décisions Android distinctes.

Première ouverture et création du PIN Famille

L’écran « Bienvenue sur ClikoSpido » présente la configuration. Vous pouvez choisir parmi dix langues et créer le code qui protège les réglages du Mode Famille.

  1. Choisissez la langue dans la liste.
  2. Dans « Créer le code PIN Famille », saisissez 4 à 8 chiffres.
  3. Confirmez exactement le même code, puis touchez Commencer.
  4. Conservez le code dans un endroit sûr : il sera demandé pour modifier les paramètres protégés.

Vous pourrez ensuite ajouter les proches, choisir les boutons visibles et adapter l’affichage dans le Mode Famille.

Pourquoi choisir ClikoSpido comme accueil principal ?

Lorsque ClikoSpido devient l’accueil principal Android, le bouton Accueil du téléphone ouvre directement son interface simplifiée. C’est idéal pour éviter de retrouver le lanceur habituel et ses nombreuses icônes.

  1. Ouvrez Mode Famille et entrez le PIN.
  2. Sélectionnez Accueil principal du téléphone.
  3. Touchez Activer ClikoSpido comme accueil principal.
  4. Dans la fenêtre Android, choisissez ClikoSpido et confirmez. Utilisez Actualiser le statut si nécessaire.
Réversible à tout moment

Dans la même rubrique, choisissez « Revenir à l’accueil Android » pour retrouver l’écran d’origine. Vos réglages ClikoSpido sont conservés.

Pourquoi choisir ClikoSpido comme Téléphone par défaut ?

Ce réglage est facultatif et différent de l’accueil principal. Il permet à ClikoSpido d’afficher sa propre interface pendant les appels, avec de grands boutons pour décrocher, refuser, raccrocher, activer le haut-parleur et afficher le clavier. Il donne aussi accès à l’historique des appels dans l’onglet Récents, sous réserve des autorisations nécessaires.

  1. Ouvrez Mode Famille → Appels dans ClikoSpido.
  2. Lisez la confirmation, puis touchez Afficher les appels dans ClikoSpido.
  3. Si Android le demande, sélectionnez ClikoSpido comme application Téléphone par défaut et acceptez les autorisations indispensables aux appels.
  4. Faites tester un appel entrant et sortant, puis un appel quand l’écran est verrouillé.
Point essentiel

Si ClikoSpido n’est pas Téléphone par défaut, l’application Téléphone d’origine continue à gérer les appels entrants. Sur certains téléphones, les notifications du répondeur dépendent de l’opérateur ou de la messagerie vocale visuelle. En cas de difficulté, utilisez « Revenir au Téléphone Android ».

Les vérifications après configuration

  • Le bouton Accueil ouvre bien ClikoSpido.
  • Les contacts et photos des proches apparaissent correctement.
  • Un appel entrant s’affiche lorsque le téléphone est verrouillé.
  • Les appels sortants et le haut-parleur fonctionnent.
  • Les notifications et le répondeur sont vérifiés avec un véritable message de test.
  • Le proche connaît le code PIN et sait revenir au Téléphone Android d’origine si nécessaire.

Vous pouvez utiliser la page Vérification du téléphone pour contrôler les réglages concernés.
