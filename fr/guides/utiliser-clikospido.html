Les grands boutons de l’accueil

L’écran principal propose les accès essentiels : Appeler, Messages, Contacts, Photos, Caméra et Urgence. Le Mode Famille permet de décider quels raccourcis afficher et dans quel ordre.

Appeler et retrouver les derniers appels

Le bouton Appeler donne accès au Clavier, aux Favoris et aux Récents. Composez un numéro sur le clavier ou touchez un contact pour lancer l’appel.

Si ClikoSpido est l’application Téléphone par défaut, son onglet Récents affiche l’historique disponible, avec les noms et les photos des contacts lorsqu’ils sont connus. Sinon, l’accès peut être redirigé vers le Téléphone d’origine.

Pour les appels entrants, la grande photo et les boutons de réponse nécessitent le rôle Téléphone par défaut. Consultez le guide de démarrage pour le configurer.

Contacter une personne grâce à sa photo

Les proches enregistrés dans le Mode Famille peuvent être affichés directement sur l’accueil. Toucher leur photo permet de les appeler plus rapidement. Selon les réglages, vous pouvez afficher une, deux ou trois personnes par ligne.

Pour changer la photo d’un contact, ouvrez Mode Famille → Mes proches et utilisez « Ajouter photo au profil » lorsque l’option est disponible.

Messages : conserver la messagerie habituelle

Le bouton Messages ouvre l’application SMS/RCS déjà utilisée sur le téléphone, comme Google Messages ou Samsung Messages. ClikoSpido ne remplace pas cette messagerie et ne lit pas vos conversations.

Depuis un contact, l’action Message peut ouvrir un nouveau message avec son numéro déjà renseigné. Vous devez toujours écrire puis envoyer le message vous-même.

Photos et appareil photo

Photos ouvre l’application de galerie compatible installée sur le téléphone ; Caméra ouvre l’appareil photo Android. Vos photos restent dans les applications habituelles du téléphone.

Le raccourci Urgence : contacter un proche

Le bouton rouge Urgence propose deux actions : un appel vers la personne choisie et la préparation d’un SMS d’urgence. Le destinataire et le texte du message sont configurés par un proche dans Mode Famille → Réglages Appel d’urgence.

Ce n’est pas un service de secours

Le raccourci Urgence sert à joindre le proche désigné. Il ne remplace pas les services publics d’urgence (112 en Europe). Le SMS n’est pas envoyé automatiquement : il faut appuyer sur Envoyer dans l’application Messages.

Accéder à d’autres applications

La page Applications affiche les applications sélectionnées dans le Mode Famille. Ajouter ou retirer un raccourci ne désinstalle pas l’application du téléphone : il ne s’agit pas d’un blocage général d’Android.

Pour modifier la sélection, utilisez Mode Famille → Applications autorisées.
