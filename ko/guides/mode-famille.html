가족 모드 열기

ClikoSpido 홈 화면에서 가족 설정을 열고 첫 실행 때 만든 숫자 4~8자리 PIN을 입력하세요. 보호된 설정은 사용자 또는 신뢰하는 사람이 조정할 수 있습니다.

Premium

ClikoSpido의 유료 옵션을 확인하고 관리합니다.

  1. 월간 구독과 평생 이용권을 확인하세요. 가격은 Google Play에 표시됩니다.
  2. 같은 Google 계정으로 Premium을 구매했다면 구매 복원을 사용하세요.
  3. 구독 취소는 Google Play에서 관리합니다. 상품 설정 후에 구매가 작동합니다.

휴대전화 홈 화면

ClikoSpido를 휴대전화의 기본 홈 화면으로 지정합니다.

  1. ClikoSpido를 기본 홈으로 설정하는 버튼을 누르고 Android 설정에서 선택하세요. 일부 기능은 Premium이 필요합니다.
  2. 홈 버튼을 누르면 ClikoSpido가 열립니다. 상태 새로고침으로 확인하세요.
  3. 원래 홈으로 돌아가려면 Android 설정에서 이전 런처를 선택하세요. 기존 설정은 유지됩니다.

ClikoSpido 통화

통화 화면을 ClikoSpido 또는 기존 Android 전화 앱으로 선택합니다.

  1. 안내를 확인하고 ClikoSpido에서 통화 표시를 선택하세요. Android에서 기본 전화 앱 지정을 요청합니다.
  2. 수신·발신 통화, 벨소리, 잠금 화면, 블루투스, 듀얼 SIM을 시험하세요.
  3. 문제가 생기면 기존 전화 앱으로 되돌리세요. 기기에 따라 전체 화면 권한이 필요합니다.

긴급 전화 설정

가족 등 연락할 사람을 정하고 긴급 문자를 준비합니다.

  1. 내 가족 목록에서 선택하거나 이름과 전화번호를 입력하세요.
  2. 긴급 SMS 내용을 수정하고 설정을 저장하세요.
  3. 문자는 기본 메시지 앱에 작성만 되며 사용자가 직접 전송해야 합니다. 긴급 구조 신고를 대신하지 않습니다.

홈 화면 꾸미기

홈 화면에 표시할 큰 버튼과 순서를 선택합니다.

  1. 각 버튼의 스위치로 표시 여부를 설정하세요.
  2. 위아래 화살표로 순서를 바꾸세요.
  3. 시니어 모드 미리보기로 확인하세요. 일부 설정은 Premium이 필요합니다.

내 가족

가족 사진을 홈 화면에 추가해 쉽게 연락합니다.

  1. 전화 연락처를 가져오거나 이름과 번호를 직접 입력하세요.
  2. 사진 추가를 누르면 Android 연락처 편집 화면이 열립니다.
  3. 홈에서 사진을 누르면 통화합니다. SMS는 평소 사용하는 메시지 앱으로 열립니다.

화면

글자 크기, 화면 배치, 사진 크기와 색상을 조절합니다.

  1. 글자 크기를 보통, 크게, 아주 크게 중에서 고르세요.
  2. 사용 가능할 경우 홈 화면은 1열 또는 2열, 가족 사진은 한 줄에 1~3명으로 배치할 수 있습니다. 한 줄의 인원이 적을수록 사진이 커집니다.
  3. 다크 모드나 고대비를 활용하세요. 일부 배치는 Premium이 필요합니다.

언어

ClikoSpido의 메뉴 언어를 선택합니다.

  1. 지원되는 10개 언어 중 하나를 누르세요.
  2. ClikoSpido에만 즉시 적용되며 Android 시스템 언어는 바뀌지 않습니다.
  3. 잘못 선택했다면 가족 모드의 언어 메뉴에서 다시 변경하세요.

허용된 앱

ClikoSpido에서 이용할 앱을 선택합니다.

  1. 가족 모드에서 표시할 앱에 체크하세요.
  2. 체크를 해제하면 ClikoSpido의 바로가기만 사라집니다.
  3. 앱이 삭제되거나 Android의 다른 곳에서 차단되지는 않습니다. 맞춤 선택은 Premium이 필요할 수 있습니다.

PIN 변경

가족 모드를 보호하는 PIN을 변경합니다.

  1. 현재 PIN을 먼저 입력하세요.
  2. 새로운 4~8자리 PIN을 입력하고 다시 확인하세요.
  3. 새 PIN 저장을 누르고 안전하게 보관하세요. 도움말에서는 PIN을 복구할 수 없습니다.
