Google Play에서 설치하기

ClikoSpido는 호환되는 Android 스마트폰의 홈 화면을 간편하게 바꿉니다. 설치해도 기존 연락처, 사진, 메시지는 삭제되지 않습니다.

  1. Google Play에서 ClikoSpido 페이지를 엽니다.
  2. 설치한 후 열기를 누릅니다.
  3. PIN을 만들기 전에 언어를 확인합니다.

첫 실행과 가족 PIN 만들기

환영 화면에서 10개 언어 중 하나를 선택하고 가족 모드 설정을 PIN으로 보호할 수 있습니다.

  1. 언어를 선택합니다.
  2. 가족 PIN 만들기에서 숫자 4~8자리를 입력합니다.
  3. 같은 PIN을 다시 입력하고 시작합니다.
  4. 설정을 변경할 때 필요하므로 안전하게 보관합니다.

왜 ClikoSpido를 기본 홈 앱으로 설정하나요?

기본 홈 앱으로 설정하면 Android 홈 버튼을 눌렀을 때 기존 런처 대신 ClikoSpido의 간편한 화면이 열립니다.

  1. 가족 모드를 열고 PIN을 입력합니다.
  2. 전화 홈 화면 설정을 선택합니다.
  3. ClikoSpido를 홈 앱으로 설정하고 Android에서 확인합니다.
  4. 필요하면 상태를 새로 고칩니다.

언제든 기존 홈 화면으로 돌아갈 수 있으며 ClikoSpido 설정은 유지됩니다.

왜 ClikoSpido를 기본 전화 앱으로 설정하나요?

선택 사항이며 홈 앱 설정과 별개입니다. 전화 받기, 거절, 끊기, 스피커, 키패드의 큰 버튼을 사용할 수 있으며 필요한 권한이 있으면 통화 기록을 볼 수 있습니다.

  1. 가족 모드 → ClikoSpido 통화 메뉴를 엽니다.
  2. 안내를 확인하고 ClikoSpido에서 통화 표시를 선택합니다.
  3. Android에서 ClikoSpido를 기본 전화 앱으로 선택하고 필요한 권한을 허용합니다.
  4. 발신, 수신 및 화면이 잠겼을 때 수신을 테스트합니다.

이 설정을 하지 않으면 기존 전화 앱이 수신 전화를 관리합니다. 음성사서함 알림은 통신사와 기기에 따라 달라집니다. 문제가 지속되면 기존 Android 전화 앱으로 돌아가세요.

설정 후 확인하기

홈 버튼, 연락처와 사진, 잠금 화면에서 수신 전화, 발신 전화와 스피커가 잘 작동하는지 확인합니다. 다른 전화기로 실제 음성 메시지를 남겨 알림을 시험하세요. 도움을 주는 가족은 PIN과 기존 전화 앱으로 돌아가는 방법을 알아 두세요.
