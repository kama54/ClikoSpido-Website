Wozu dient die Telefondiagnose?

Sie erkennt Android-Einstellungen, die Anrufe oder Mailbox-Hinweise beeinträchtigen können: Standard-Telefon-App, Berechtigungen, Benachrichtigungspriorität, Vollbild, Mailbox-Signale und Herstelleroptionen.

Ein erfolgreicher Check garantiert keine echten Anrufe oder Hinweise. Testen Sie beides.

Diagnose öffnen

  1. Öffnen Sie den Familienmodus und geben Sie die PIN ein.
  2. Wählen Sie Anrufe in ClikoSpido.
  3. Starten Sie die Diagnose im Abschnitt zur Telefonprüfung.
  4. Korrigieren Sie angezeigte Punkte und aktualisieren Sie das Ergebnis.

Ergebnisse verstehen

Ein korrekter Status bestätigt die erkannte Einstellung. Ein Korrekturhinweis erfordert eine Änderung. Ein Prüfhinweis bedeutet, dass ClikoSpido den Wert nicht automatisch feststellen kann. Android-Menüs unterscheiden sich je nach Gerät.

Eingehende Anrufe prüfen

Prüfen Sie die Standard-Telefon-App, erlaubte Benachrichtigungen, deren Priorität und die Vollbildanzeige. Ab Android 14 kann eine besondere Erlaubnis erforderlich sein. Testen Sie einen Anruf bei gesperrtem Bildschirm.

Mailbox prüfen

Geprüft werden Erkennungsberechtigung, Mailbox-Hinweise, Überwachung und empfangene Signale. Der Benachrichtigungstest erzeugt nur einen lokalen Testhinweis, keine echte Nachricht.

  1. Erlauben Sie Benachrichtigungen und Mailbox-Erkennung.
  2. Starten Sie den Test und prüfen Sie das Benachrichtigungsfeld.
  3. Hinterlassen Sie eine echte Nachricht von einem anderen Telefon.
  4. Aktualisieren Sie die Diagnose und prüfen Sie Hinweise von Android oder Netz.

Visuelle Mailbox und Anbieter

Manche Geräte nutzen eine visuelle Mailbox des Anbieters oder der ursprünglichen Telefon-App. ClikoSpido unterstützt diese derzeit nicht. Ein erkannter möglicher Dienst beweist nicht, dass er aktiv ist oder Hinweise blockiert.

Wenn echte Hinweise fehlen, fragen Sie beim Anbieter nach der klassischen Mailbox oder kehren zur ursprünglichen Telefon-App zurück. Ändern Sie Anbieteroptionen nicht ohne Kenntnis der Folgen.

Xiaomi, Redmi und POCO

Bei manchen MIUI/HyperOS-Geräten können Sperrbildschirm-Anzeige, Hintergrundfenster, Autostart und Akku-Beschränkungen Anrufe beeinträchtigen. Diese Herstelleroptionen lassen sich nicht immer automatisch prüfen. Öffnen Sie die vorgeschlagenen Einstellungen und testen Sie anschließend einen Anruf.

Hilfe anfordern

Notieren Sie Hersteller, Modell, Android-Version, Symptome und relevante Diagnoseergebnisse. Senden Sie keine privaten Nummern, Kontaktnamen oder Bildschirmfotos mit persönlichen Daten.
